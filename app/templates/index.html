业务背景、演示步骤与样例说明（点开看全部口径）

谁在用：数据质量组（每月抽检一次上游商品主数据）。 痛点：① 分数靠人工拍脑袋，无法复现；② 同一行的多个问题被拆成多张工单，下游反复返工； ③ 小品类被大品类规则误判成异常，整改要求站不住脚。

系统替代哪一段：把抽检 CSV 交给规则集，自动算缺失率、业务键/整行重复、按品类分组的双法异常值， 给出百分制分数与 A/B/C/D 分级，并把同一单元格的多条命中合并成一张整改工单，CSV 下发。

演示步骤（每步都真实可点）

  1. 打开 抽检工作台：直接选「内置样例 quality_sample.csv」或上传自己的 CSV（9 列 2000 行）。
  2. 点「执行剖析」：页面按 7 个阶段显示进度（载入 → 缺失 → 重复 → 异常 → 校验 → 评分 → 告警），完成后自动跳到结果页。
  3. 结果页看：总分与分级、每列违规率表、high/medium 告警（同一单元格只出现一条，rules[] 保留全部命中规则）、样本不足品类说明。
  4. 去 复核与工单：改权重 → 用新权重重算 → 体会分数变化；下载工单 CSV（row_id / column / rules / severity / 建议）。
  5. 故意制造错误：上传一份缺列 CSV（例如删掉 price 列），接口返回 400 与中文原因，页面可恢复重试。
